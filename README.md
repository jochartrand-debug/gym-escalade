# Gym d'escalade privé — V1

Maquette fonctionnelle du formulaire mobile.

## Cette version
- fonctionne dans le navigateur;
- comprend l'identification, les règles, la reconnaissance des risques et la signature tactile;
- n'envoie encore aucune donnée à Supabase.

## Installation GitHub
Décompresser le ZIP et téléverser `index.html`, `style.css`, `app.js` et le dossier `assets` à la racine du dépôt `gym-escalade`.

La connexion Supabase sera ajoutée après le test de cette interface.
